## Context

Geomove is a digital platform supporting the collective force of change by gathering and promoting citizen initiatives by children and young people in Belgium, Benin and Togo. Initially recruited for 1 or 2 features before production release, I ended up working 2 months with the Cherry Pulpe team in 2023.

## Key Features

- Event invitation workflow
- Event and project cloning system — allowing participants to copy and adapt projects or events they enjoyed
- Comment system (complete overhaul of a non-functional existing base)
- Numerous bug fixes and stabilization before production release

## Technical Highlights

- Laravel + WordPress (content and language management) + Vue.js architecture
- Integration into an existing development team with ongoing code takeover
- Development of features beyond the original scope at client request
- Close collaboration with the Cherry Pulpe team
