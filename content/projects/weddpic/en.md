## Context

weddPic is a personal application I designed and developed in one month at the beginning of 2026. It manages wedding photos and galleries: each guest can take photos that are automatically shared with built-in moderation. The application also supports connecting custom selfie booths (iPad, iPhone) that run in automatic mode so guests can freely take photos.

## Key Features

- Shared photo gallery with automatic upload between guests
- Photo moderation system
- Custom selfie booth integration (iPad, iPhone) in autonomous mode
- Complete wedding event management

## Technical Highlights

- Laravel (backend) + Nuxt 4 with NuxtUI (frontend) architecture
- PostgreSQL database
- Full ownership: graphic design, UI/UX, backend, frontend, tests
