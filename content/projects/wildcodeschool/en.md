## Context

Wild Code School is a coding school offering intensive bootcamps. For 11 months in Brussels, I guided a full cohort of web developers through a 10-month program covering frontend, backend and databases.

## Subjects Taught

- React — components, routing, state management, full projects
- Node.js — REST APIs, Express, server architecture
- HTML & CSS — integration, responsive design, best practices
- SQL — modeling, queries, joins, optimization

## Teaching Approach

- Planning and delivering interactive lessons focused on React, Node.js, HTML, CSS and SQL
- Individual student support to strengthen understanding and develop practical skills
- Progress evaluation and teaching method adaptation to meet each student's specific needs
- Mentoring on real-world projects to prepare students for their future careers in tech
