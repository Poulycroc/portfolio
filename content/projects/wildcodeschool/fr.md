## Contexte

La Wild Code School est une école de code proposant des bootcamps intensifs. Pendant 11 mois à Bruxelles, j'ai guidé une promotion complète de développeurs web à travers un programme de 10 mois couvrant le frontend, le backend et les bases de données.

## Matières enseignées

- React — composants, routing, state management, projets complets
- Node.js — API REST, Express, architecture serveur
- HTML & CSS — intégration, responsive, bonnes pratiques
- SQL — modélisation, requêtes, jointures, optimisation

## Approche pédagogique

- Planification et mise en œuvre de leçons interactives axées sur l'apprentissage de React, Node.js, HTML, CSS et SQL
- Soutien individuel aux étudiants pour renforcer leur compréhension et développer leurs compétences pratiques
- Évaluation des progrès et adaptation des méthodes d'enseignement pour répondre aux besoins spécifiques de chacun
- Accompagnement sur des projets réels pour préparer les étudiants à leur future carrière dans le numérique
