## Fonctionnalités clés

- Application métier React / Symfony
- Flux d'intégration entre systèmes HASTUS/GIRO
- Monitoring applicatif via Grafana
- Logs structurés pour la fiabilisation des traitements

## Points techniques

- Migration de pipelines legacy vers des solutions maintenables
- Mise en place de monitoring et alerting (Grafana)
- Analyse fonctionnelle et technique avec les équipes métier (dispatch, exploitation, IT)
- Améliorations UX basées sur les retours utilisateurs
