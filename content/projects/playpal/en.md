## Context

PlayPal is an event management application dedicated to tabletop role-playing games and more generally to in-person games. Developed solo in 2 weeks in 2019.

## Key Features

- Event management: dates, venues, details
- Participant registration system
- Team management
- Invitation system from admin or existing members

## Technical Highlights

- Laravel (backend) + Vue.js (frontend) architecture
- MariaDB database
- Complete solo development
