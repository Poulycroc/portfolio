## Contexte

ArkDevel est la structure que j'ai co-fondée en 2017 à Namur. GIMI fait partie des applications métier que nous avons conçues et développées pour nos clients — des outils SaaS sur mesure couvrant la gestion, le reporting et l'automatisation de processus.

## Fonctionnalités clés

- Back-offices et dashboards de gestion adaptés aux besoins métier
- API REST complète et documentée
- Système de gestion multi-clients
- Interfaces utilisateur pensées pour les utilisateurs finaux, pas juste les développeurs

## Points techniques

- Décisions d'architecture et design d'API REST de bout en bout
- Modélisation de bases de données MySQL optimisées
- Cycle produit complet : analyse des besoins clients, échanges directs, UI/UX, développement, déploiement et itérations
- Intégration d'outils d'IA dans le workflow de développement pour accélérer les livraisons
