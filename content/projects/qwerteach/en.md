## Context

Qwerteach is a Brussels-based online tutoring platform. The goal: making education more accessible and flexible by connecting students and tutors through an intuitive marketplace. I contributed to the project for 8 years as a fullstack developer.

## Key Features

- Student/tutor matching marketplace with advanced search
- Online booking and payment system
- Personalized dashboard for tutors and students
- Integrated messaging and video conferencing
- Responsive UI built with Bootstrap and Element-UI

## Technical Highlights

- Long-term development and maintenance (8 years) in production — stability, performance and continuous evolution
- Ruby on Rails backend with structured API and complex business logic
- Vue.js 2 frontend for optimal user experience
- Redis integration for application performance optimization
- Container deployment and management via Docker
- SASS for CSS maintainability
