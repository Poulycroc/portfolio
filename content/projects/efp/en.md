## Context

EFP (Espace Formation PME) is a vocational training center in Brussels. For 8 months, I shared my frontend web development expertise with students preparing to enter the professional tech world.

## Subjects Taught

- ReactJS — components, hooks, state management
- JavaScript — ES6+, DOM manipulation, async/await
- HTML & CSS — semantics, responsive design, Flexbox/Grid
- PHP — backend fundamentals, forms, server interactions

## Teaching Approach

- Dynamic course design centered on hands-on learning of ReactJS, HTML, CSS, JavaScript and PHP
- Student skills evaluation and personalized feedback to improve proficiency
- Teaching methods adapted to individual student needs
- Continuous tech watch to keep training relevant and up to date
